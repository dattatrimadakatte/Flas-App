# ✅ Flask Todo Application

A simple Todo management web application developed using Python Flask, Flask-SQLAlchemy and MySQL.

## 📌 Project Overview

The Flask Todo Application allows users to manage their daily tasks through a simple web interface.

Users can add new Todo items, view existing tasks and delete tasks when they are no longer required.

The application uses Flask for the backend, SQLAlchemy for database operations and MySQL for storing Todo information.

## ✨ Features

* Add new Todo tasks
* View all Todo tasks
* Delete Todo tasks
* Store Todo data in MySQL
* Database integration using SQLAlchemy
* HTML form handling
* Simple and responsive interface
* Automatic date and time for Todo creation

## 🛠️ Technologies Used

* Python
* Flask
* Flask-SQLAlchemy
* SQLAlchemy
* MySQL
* PyMySQL
* HTML
* CSS

## 🗄️ Database

The application uses MySQL to store Todo information.

Each Todo contains:

* Todo number
* Title
* Description
* Date created

SQLAlchemy is used as an ORM to communicate with the MySQL database.

## 🔄 Application Workflow

1. User opens the Todo application.
2. Existing Todo items are displayed.
3. User enters a title and description.
4. The Todo is submitted through the form.
5. Flask receives the request.
6. SQLAlchemy stores the Todo in MySQL.
7. The updated Todo list is displayed.
8. Users can delete a Todo using its Todo number.

## 🎯 Objective

The objective of this project is to understand and implement a basic full-stack web application using Flask and a relational database.

This project demonstrates backend development, database integration, routing, form handling and CRUD operations.
